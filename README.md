# AI Career Assistant 🚀

An AI-powered Career Assistant web application that helps users with resume analysis, career guidance, interview preparation, and skill roadmaps using Llama 3.

---

## ✨ Features

- 🤖 AI Chatbot for career guidance
- 📄 Resume PDF analysis
- 🎯 ATS-style feedback on resumes
- 🧠 Skill recommendations
- 🗺️ Learning roadmaps
- 💬 Chat history support 
- ⚡ Fast API backend with Llama 3

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Axios
- HTML, CSS, JavaScript

### Backend
- FastAPI
- Python
- PyMuPDF (PDF parsing)
- OpenAI SDK (used with Groq / Llama 3)
- Uvicorn

### AI Model
- Llama 3 (via Groq API)
